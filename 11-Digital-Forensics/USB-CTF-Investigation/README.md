# 🔍 USB Digital Forensics Investigation

> **A complete forensic examination of a USB storage device image using SIFT Workstation and open-source forensic tools.**

---

# 📖 Case Summary

This investigation was conducted as part of a Digital Forensics & Incident Response Capture The Flag (CTF) challenge.

The objective was to examine the forensic image **`cartel.img`** using accepted forensic methodologies while preserving evidence integrity throughout the investigation.

The examination included:

- Evidence Verification
- Initial Triage
- File System Analysis
- Artifact Discovery
- Deleted File Recovery
- Timeline Reconstruction
- Professional Forensic Reporting

---

# 🎯 Objectives

The objectives of this investigation were to:

- Verify the integrity of the forensic image.
- Identify the underlying file system.
- Discover significant digital artifacts.
- Recover deleted files.
- Reconstruct a timeline of activity.
- Produce an evidence-based forensic examination report.
