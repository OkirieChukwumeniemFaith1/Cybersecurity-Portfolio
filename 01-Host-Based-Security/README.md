> **Protecting endpoints through secure configuration, monitoring, hardening, and defensive security practices.**

# 📖 Module Overview

Host-Based Security focuses on securing individual computer systems against unauthorized access, malware, privilege escalation, persistence mechanisms, and other endpoint-based threats.

This module documents the practical work completed during my cybersecurity training and demonstrates the concepts, tools, and defensive techniques used to secure host systems.
